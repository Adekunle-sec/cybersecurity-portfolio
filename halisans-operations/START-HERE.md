# Halisans Technologies | Role-Specific GitHub Portfolio Pack

Four independent, editable GitHub README templates: IAM, SOC, Security Analysis, and GRC. Each role includes four starter case-study templates.

## How to use
1. Select your career pathway folder and copy its `README.md` to your GitHub profile repository (`your-username/your-username`) or a portfolio repository.
2. Replace placeholders with verified details and remove any activities you have not performed.
3. Complete the case studies and add **approved, sanitized** evidence. Links in the README point to the bundled case-study templates.
4. Update independent projects with genuine repository URLs.
5. Pin your strongest 3–6 repositories on GitHub and keep the landing page current.

## Ethical representation
Do not equate mentee training with paid employment. Clearly label simulated versus real-world work. Obtain Halisans authorization before publishing internal material. Never upload passwords, API keys, sensitive IP addresses, identifiable logs, customer data, or internal tickets.

## Note
The four sample cases per role are scaffolds, not claims of completed work. Project outcomes and metrics must be supported by evidence.
